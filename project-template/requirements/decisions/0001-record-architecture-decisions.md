# ADR-0001：採用架構決策紀錄 (ADR)

## 狀態
已定案 (Accepted)

## 背景 (Context)
本專案採規格驅動開發，未來需依文件重新生成程式碼與硬體設計。
若不記錄「當初為什麼這樣選」，重建時 AI 或工程師會做出不同選擇，導致結果不等價。

## 決策 (Decision)
所有具長期影響的技術/架構選擇，都以一份 ADR 記錄於 `requirements/decisions/`。
編號遞增（0001、0002…），一經定案不刪除；若被推翻，新增一份標記 "取代 ADR-XXXX"。

## 後果 (Consequences)
- 優點：重建有依據、決策可追溯、新成員能快速理解「為什麼」。
- 成本：每個重大決策需花數分鐘撰寫。
