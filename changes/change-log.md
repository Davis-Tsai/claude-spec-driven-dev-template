# 變更紀錄 (Change Log)

> **用途**：集中管理「已定案文件」每一次的修改，讓將來能追溯「改了什麼、為什麼改」，
> 同時確保 PRD / ERD / 契約 / 驗收等相關文件都同步更新到最新。
>
> **何時新增一筆**：任何「已定案」文件要修改時 —— 先把該文件狀態改為「修改中」，
> 與使用者討論修改方案，方案確定/修改完成後，由 AI 在此新增一筆紀錄，
> 並同步更新所有受影響文件，最後把狀態改回「已定案」。
>
> 編號遞增（CHG-0001、CHG-0002…），**永不刪除**。最新的加在最上面。

---

## 紀錄範本（複製此段新增變更）

```
### CHG-NNNN：<一句話標題>
- 日期：<YYYY-MM-DD，或以 git commit 為準>
- 狀態：提議中 | 已套用
- 動機 / 為什麼改：
- 變更內容摘要：
- 受影響文件（全部要同步更新到最新）：
  - [ ] requirements/PRD.md（FR-___ / NFR-___）
  - [ ] requirements/ERD.md（追溯表、軟硬體邊界）
  - [ ] contracts/________（schema / API / 硬體規格）
  - [ ] acceptance/________（AC-___ / HW-AC-___）
- 是否需重生程式碼：是 / 否（若是，重生後跑 acceptance 測試）
- 關聯：ADR-____（若涉及架構決策）、commit <hash>
```
