# 硬體驗收測試程序

> 硬體無法「跑單元測試」，改以標準化的量測程序作為驗收依據。
> 每項對應一條 PRD 需求，可重複執行、可記錄數據。

## HW-AC-001：電源功耗驗證（對應 NFR-003）
- **設備**：直流電源供應器、電流表
- **步驟**：
  1. 施加 5.0V 輸入。
  2. 進入工作模式，量測工作電流。
  3. 進入睡眠模式，量測睡眠電流。
- **合格標準**：工作電流 ≤ ___ mA；睡眠電流 ≤ ___ µA。
- **實測值**：______（測試人 / 日期）

## HW-AC-002：通訊時序驗證（對應 timing.md）
- **設備**：邏輯分析儀 / 示波器
- **步驟**：量測 I2C SCL 頻率與訊號完整性。
- **合格標準**：400 kHz ± 5%，無明顯 glitch。
- **實測值**：______

## HW-AC-003：開機就緒時間
- **步驟**：上電至韌體回報 ready，量測時間。
- **合格標準**：< ___ ms。
- **實測值**：______
