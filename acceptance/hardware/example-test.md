# 硬體驗收測試程序

> 硬體無法「跑單元測試」，改以標準化的量測程序作為驗收依據。
> 每項對應一條 PRD 需求，可重複執行、可記錄數據。
>
> **每項必填**：
> - **參考標準與精度**：用什麼當真值、其不確定度。參考精度須**明顯優於**被測規格（例：手轉＋目測只有 ±10~15°，驗不了 ±1° 的規格；改用步進馬達治具定位）。
> - **測試設備干擾與隔離**：量測/除錯設備本身可能如何改變結果（除錯器擋住重置、只重置核心使周邊殘留、探棒負載、序列終端機佔用埠…），以及隔離方法（拔隔離跳線、斷開除錯器、獨立電源）。
>
> 已定案後只填「實測值」欄、不改步驟或合格標準時，免走 CHG（見 `CLAUDE.md §4`）。

> ⚠️ 範例可刪：下方為格式示範。

## HW-AC-001：電源功耗驗證（對應 NFR-003）
- **設備**：直流電源供應器、電流表
- **參考標準與精度**：電流表 ±(0.5%+2 digits)，解析度 1 µA（優於睡眠電流規格一個數量級）
- **測試設備干擾與隔離**：除錯器經 USB 供電會灌入電流 → 量測時拔除除錯器、改由電源供應器單獨供電
- **步驟**：
  1. 施加 5.0V 輸入。
  2. 進入工作模式，量測工作電流。
  3. 進入睡眠模式，量測睡眠電流。
- **合格標準**：工作電流 ≤ ___ mA；睡眠電流 ≤ ___ µA。
- **實測值**：______（測試人 / 日期）

## HW-AC-002：通訊時序驗證（對應 timing.md）
- **設備**：邏輯分析儀 / 示波器
- **參考標準與精度**：取樣率 ≥ 10× 訊號頻率（400 kHz → ≥ 4 MS/s）
- **測試設備干擾與隔離**：探棒電容會拉慢邊緣 → 用低電容探棒，並比對接/不接探棒時功能是否一致
- **步驟**：量測 I2C SCL 頻率與訊號完整性。
- **合格標準**：400 kHz ± 5%，無明顯 glitch。
- **實測值**：______

## HW-AC-003：看門狗重置驗證
- **設備**：目標板、序列終端機
- **參考標準與精度**：以重置原因暫存器 + 開機訊息計數判定；觸發來源須是**本測試的故意卡死**，非其他操作
- **測試設備干擾與隔離**：JTAG 除錯器連線時會擋住晶片重置，必得「不合格」的假結論 → 測前**拔掉除錯器隔離跳線**；建置/燒錄腳本也會發重置，讀重置原因前確認最近一次重置不是自己的操作造成
- **步驟**：以測試建置送「故意卡死」命令，觀察是否在逾時內自動重置並回報 ready。
- **合格標準**：< ___ ms 內重置並恢復。
- **實測值**：______
